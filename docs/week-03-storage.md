# 3주차 선택 미션: 브라우저 저장소

목록의 '북마크 저장'에서 저장 방식을 선택한다. 목록, 검색, 상세는 같은 Zustand store를 사용한다.
기본은 '계속 저장'이며, Zustand persist가 Local Storage의 `umcine-bookmark-store`에 저장한다.
'현재 탭만 저장'을 선택하면 Session Storage의 같은 키에 저장한다.

저장 방식을 바꾸면 현재 북마크를 새 저장소로 옮긴 뒤 이전 저장소의 북마크 키를 정리한다.
따라서 계속 저장에서 현재 탭만 저장으로 바꾸고 탭을 닫으면, 옮긴 북마크는 사라진다.
현재 탭만 저장에서 계속 저장으로 다시 바꾸면 현재 북마크를 계속 유지할 수 있다.
저장 방식 선택은 Session Storage의 `umcine-bookmark-storage-mode`에 저장한다.
새 세션에서는 기본인 계속 저장으로 돌아온다.
기존 배열 및 이전 sessionStorage 실습 데이터는 새 형식으로 한 번 이관한다.

| 동작 | 계속 저장: localStorage | 현재 탭만 저장: sessionStorage |
| --- | --- | --- |
| 같은 탭에서 새로고침 | 유지 | 유지 |
| 탭을 닫고 새 탭으로 접속 | 유지 | 초기화 |
| 브라우저를 닫고 새로운 세션으로 접속 | 유지 | 초기화 |

브라우저의 닫은 탭 복원이나 세션 복원은 sessionStorage를 복원할 수 있다.
탭 종료 실습은 기존 탭을 복원하지 않고 새 탭에 주소를 입력해 확인한다.
기존 탭에서 복제하거나 opener를 통해 연 탭은 초기 세션 데이터를 복사할 수 있다.
저장소는 주소와 포트별로 구분되므로 개발 서버를 다시 켤 때 같은 주소로 접속한다.

목록의 '큰 화면의 카드 열 수'에서 3열 또는 5열을 선택한다.
설정은 Local Storage의 `umcine-grid-columns`에 저장하며, 기본값은 5열이다.
1025px 미만에서는 기존 반응형 열 수를 유지한다.

## 직접 확인

1. 기본 모드에서 북마크하고 목록, 검색, 상세의 표시를 확인한다.
2. 새로고침 및 브라우저 재실행 후 같은 북마크가 유지되는지 확인한다.
3. Application → Local Storage에서 `umcine-bookmark-store`를 확인한다.
4. 현재 탭만 저장으로 바꾸고 Application → Session Storage에서 같은 키를 확인한다.
5. 선택한 저장소의 키를 삭제하고 새로고침하면 빈 상태가 된다.
6. 현재 탭만 저장에서 탭을 닫고 새 탭으로 접속하면 북마크는 초기화되고 카드 열 수는 유지된다.

메모리 저장소 테스트로 전환, 복원, 새 세션 초기화, 삭제 및 잘못된 JSON 복구를 검증했다.
`pnpm build`를 실행했다. 연결된 브라우저가 없어 실제 탭 종료 및 재실행은 미검증이다.
