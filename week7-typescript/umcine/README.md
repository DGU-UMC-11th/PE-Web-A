# UMCine 7주차

```sh
pnpm install --frozen-lockfile
pnpm dev
```

영화 화면에는 기존 TMDB 환경 설정을 사용합니다. 회원가입 API의 기본 주소는 `http://localhost:8080`이며 `.env.local`의 `VITE_API_BASE_URL`로 바꿀 수 있습니다. 이번 실서버 검증은 7주차 Spring Boot·MySQL 서버를 8084에서, 프런트엔드를 5198에서 실행하여 진행했습니다. 백엔드 CORS 허용 주소는 http://127.0.0.1:5198입니다. 사용 가능한 환경 변수 이름은 `.env.example`에 있습니다.

| 경로 | 동작 |
| --- | --- |
| /signup | 입력 검증, 이메일·닉네임 중복 확인, 회원가입 API 요청 |
| /login | 이메일과 비밀번호 입력 및 제출 UI |
| /me | 예시 회원 정보 조회 |
| /me/edit | 닉네임 수정 및 조회 화면 반영 |

내 정보 변경은 앱 메모리에 저장되어 새로고침하면 초기화됩니다. 첨부 시안을 바탕으로 회원 화면을 구성했습니다. 내 정보 수정에서 닉네임 중복 확인과 프로필 이미지 미리보기를 사용할 수 있습니다.
